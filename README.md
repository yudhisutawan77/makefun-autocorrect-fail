## Entry

> I texted Grandma 'I love you' — autocorrect sent 'I loathe you' and she replied 'I always knew' before leaving the family group chat.

One line, 133 characters. `main.py` (Python, stdlib only) writes this exact text to `$ENTRY_OUT`, whether it is a file or a directory (in which case `entry.txt` is created inside it).

## Run

```sh
ENTRY_OUT=/output/entry.txt python3 main.py
```
